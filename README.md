# search-procedure

A skill for Claude to read before searching (code, papers, products, documents, personal notes — any work that involves searching through content). It structures what you want into the conditions that can't be dropped and what the thing does, then searches with terms derived from that structure, including far analogy. This lets you find existing things whose names you don't know.

- `search-procedure/` — Japanese
- `search-procedure-en/` — English
